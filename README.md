Entry for [make.fun — Make the AI judge rich](https://make.fun/c/ai-judge-rich-01)
(`ai-judge-rich-01`): a program that writes one plan to `/output/entry.txt` —
the plan an AI agent would follow to turn $100 into the most money in 30 days.

The plan: sell a done-for-you missed-call rescue to US roofers, plumbers and
HVAC firms that already run Google Ads but have no working website — build each
a live one-page site first, then sell it for $249.
